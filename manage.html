Manage students (Admin)

Create the login list

Type everything here, press Generate, then copy the result into users.js on GitHub. Passwords and register numbers are stored only as scrambled codes, so nobody can read them in your repository.

Capital/small letters do not matter for register numbers. You can paste a whole column from Excel.

How to update on GitHub

  1. Open your repository and click the file users.js.
  2. Click the pencil (Edit) icon.
  3. Select all, delete, paste the new text, then press Commit changes.
  4. Wait a minute. New students can log in; removed students cannot.

Tip: keep your register-number list saved somewhere safe. This page cannot show old numbers back, because they are stored only as codes.
