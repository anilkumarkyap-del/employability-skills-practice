Manage students (Admin)

Create the login list

Type everything here, press Generate, then copy the result into users.js on GitHub. Passwords, register numbers and names are stored only as scrambled codes, so nobody can read them in your repository.

Write the register number first, then a space (or | or comma) and the name. The name is optional. Capital/small letters do not matter for register numbers. Names are stored scrambled, and appear only after a student logs in.

How to update on GitHub

  1. Open your repository and click the file users.js.
  2. Click the pencil (Edit) icon.
  3. Select all, delete, paste the new text, then press Commit changes.
  4. Wait a minute. New students can log in; removed students cannot.

Tip: keep your register-number list saved somewhere safe. This page cannot show old numbers back, because they are stored only as codes.
